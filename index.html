Stop hunting for folders.

Finder, recent editors, and generic launchers do not know which folder is a project or what you run there.

Add a folder Save the project name, path, category, tags, and color once.
Choose a launcher Open Finder, VS Code, Terminal, or any custom macOS app.
Run the command Pin reusable commands and start them from the project detail panel.

A workspace shaped around code.

Projekt organizes projects by client, product, or personal area while keeping search and one-click actions in reach.

Project registry

Keep descriptions, filesystem paths, categories, tags, colors, hidden states, and manual ordering together.

Command templates

Pin common shell commands per project and launch them without rebuilding the command from memory.

Local storage

SQLite keeps project data on the machine. There is no account, sync layer, or cloud dependency.
